## Description

As an administrator, I want to review a customer's heat pump application so that I can approve or reject it.

## Acceptance Criteria

AC1. An administrator can open a submitted heat pump application.

AC2. The administrator can approve an application.

AC3. The administrator can reject an application and provide a rejection reason.

AC4. An approved application changes its status to Approved.

AC5. A rejected application changes its status to Rejected.
