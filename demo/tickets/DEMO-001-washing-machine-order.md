## Description

As a customer, I want to purchase a washing machine so that I can confirm my purchase and receive my order confirmation.

## Acceptance Criteria

AC1. After successful payment, the customer sees a confirmation page.

AC2. The confirmation page displays the order reference, selected washing machine model, delivery date and total price.

AC3. The customer receives a confirmation email containing the order reference and delivery date.

AC4. The order appears in the admin portal with status Paid.

## Out of scope

- Changing the payment provider.
- Sending SMS notifications.
- Changing the existing email design.
