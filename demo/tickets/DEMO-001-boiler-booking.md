## Description

As a customer, I want to book a boiler installation so that I can confirm my purchase and receive my booking confirmation.

## Acceptance Criteria

AC1. After successful payment, the customer sees a confirmation page.

AC2. The confirmation page displays the order reference, selected boiler package, installation date and total price.

AC3. The customer receives a confirmation email containing the order reference and installation date.

AC4. The order appears in the admin portal with status Paid.

## Out of scope

- Changing the payment provider.
- Sending SMS notifications.
- Changing the existing email design.
